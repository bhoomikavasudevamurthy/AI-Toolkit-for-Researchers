# AI-Toolkit-for-Researchers

## About This Repository

This repository is a curated collection of powerful AI tools that improve productivity, research efficiency, automation, and knowledge management.

I created this repository as part of my transition into the IT ecosystem, documenting technologies that bridge domain expertise and modern computing.


## Categories Covered

### AI Research Assistants

* ChatGPT – literature understanding and summarization
* Perplexity – fast research with citations
* Elicit – research paper discovery

### Automation Tools

* n8n – workflow automation
* Zapier – no-code integrations

### Computer Vision Platforms

* Roboflow – dataset creation and model deployment

### Knowledge & Documentation

* Notion AI – structured thinking and notes
* Obsidian – building interconnected knowledge

Technology is becoming essential across every discipline.
